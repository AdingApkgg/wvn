# 后台内部统计与 Recharts

用户要求接入 Recharts，展示内部统计，不包含 Umami。沿用 M3 和现有管理员授权，使用专用独立副本开发，避免覆盖另一个会话的 oRPC 改造。

## 统计口径

- 总量与当前状态：用户、管理员、公开主页、有效会话、通行密钥、作品/版本、书架、阅读启动和累计已记录时长、云存档/历史版本、被引用的存档对象字节数、未过期启用分享、待审核分享、未处理举报及管理操作。
- 7/30/90天趋势按北京时间补齐日期：新增用户、阅读启动、新建存档版本、创建分享和管理操作。今天只统计截至生成时刻的数据。
- 分布：书架状态、分享状态、内容资格、版本引擎与发布状态、有效的作品页面分级。过期、撤回与封禁不计入启用数，目标版本下线仍可能使启用分享无法访问；重复存档引用不能重复累计对象字节。
- 累计作品排行：已记录阅读时长和阅读次数，显示目录名称；排行和累计卡片不伪装成选定日期内的量。
- 站内阅读计数是现有30分钟去重的业务计数，不称为 PV/UV。现有累计秒数无法准确拆分到每日，不制造每日阅读时长；会话数不称为在线人数。对象字节数是存档元数据统计，不是磁盘实际容量。

## 实现与验证

新增只读 `/api/dash/statistics?days=7|30|90`，受同一动态管理员守卫保护、禁止缓存，只返回聚合数据，不返回用户名、会话标识、访客键、存档正文/文件名、恢复码或Umami信息。账号统计在有超时限制的只读一致性事务内计算；目录异常明确显示不可用，不能伪造为零。暂不新增统计迁移或采集任务。

新增 `dashboard-statistics` DTO、服务端聚合模块、概览页面及图表组件；概览按需加载 Recharts，其他公开页面不加载该库。采用折线、柱状分布和排行表，图表提供数值表格、空态、失败重试、7/30/90天切换及生成时间。

先编写PG和权限失败测试，再实现查询和UI。重点验证北京时间边界/补零、范围参数、未过期启用分享和去重字节、管理员/普通账号边界、聚合隐私字段、目录故障；远程安装/类型检查/构建及320/390/768/1440浏览器图表验收。只使用现有代理，独立持久任务保留回执；本机不安装或构建，生产不变更。
