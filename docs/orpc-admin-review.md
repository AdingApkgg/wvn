# 后台迁移复核

静态复核覆盖后台业务输出、nullable 字段、动态前缀、账号错误类型和审计请求体顺序。目录原始版本与列表投影、分享审核队列、内容资格默认值均与契约相符；站内聚合已排除私有令牌登录过程。账号客户端先把业务错误转换为 `AccountClientError`，近期认证提示仍可触达。

发现分享审核操作缺少 catch，业务拒绝会成为未处理 Promise；已补充中文错误提示和仅在401时退出审核状态。刷新失败保留现有队列，按钮可重试；审核成功后刷新失败会单独提示队列加载失败，避免暗示需要重放已保存的操作。目录冲突和内容资格操作恢复中文错误说明，失败不清空输入。

审计中间件在契约解析之前克隆请求体，契约之后复用 Hono 正文缓存；未发现本轮新增的消费顺序问题。本次仅静态复核与 diff 检查，远程验证和浏览器操作结果由主代理统一记录。
