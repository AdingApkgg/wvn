# 目录主体复用设计与实施记录

目标：公共目录到作品页先呈现已取得的主体，后台照常验证最新权限和版本；测量相对PR #11的收益。用户已授权该方向，生产部署仅先执行PR #11。

设计：仅复用无筛选公共目录中已审核SFW作品的公开投影，内存最多100部、30秒过期，不存统计/分享/账号信息，不持久化。不复用受限、未审核、筛选快照或查询参数页。账号/浏览权限变化、离开标签页时清空。clientLoader立即启动serverLoader，命中时把最新结果作为Promise交给Await，先展示快照；最新结果失败/删除/拒绝时替换为错误/权限状态，不继续停留在旧主体。直接打开与无JS保持SSR。复用期间不开放书架写操作。

技术：现有React Router clientLoader、Suspense/Await、公开内容投影；不新增依赖、共享缓存或生产权限配置。
