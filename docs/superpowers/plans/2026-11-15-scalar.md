# Scalar 接入

用户要求在已接入的 oRPC/OpenAPI 上使用 Scalar。直接实现管理员专用文档 `/dash/api`，不重复询问已有业务范围，不发布生产。

选择独立 Hono 文档页与同源 Scalar standalone 脚本，避免 SSR React/Vue 包装器和现有 Tailwind 样式层冲突。`/api/dash/openapi.json`、`/api/dash/reference/scalar.js`、`/api/dash/reference/bootstrap.js` 与文档页共用站内管理员 guard。文档只描述当前 listener 上的聚合契约；CLI 导出继续包含私有 listener 的独立路径。

页面支持浏览、搜索、下载和测试请求。所有文档与测试请求限定本站 /api/ 路径，禁止远程代理、外部服务器和重定向；请求前从 /api/me 重新取得绑定，认证数据不写 localStorage。Scalar脚本来自锁定npm依赖的本地文件，禁用默认远程字体、遥测与外部客户端入口；保留站点隔离头。
