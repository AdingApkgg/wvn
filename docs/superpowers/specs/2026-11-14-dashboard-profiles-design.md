# WVN 全站后台与个人主页

日期：2026-11-14。状态：用户已确认设计及数字自增公开 UID，授权开发和隔离验证。

## 目标与现状

用户选择全站后台：以 `/dash` 统一管理作品、版本、用户、内容分级和分享审核，以 `/u/:id` 提供用户公开主页。沿用现有 M3、shadcn/ui、Motion 和移动端适配。

当前目录管理由 `src/server/http.ts` 的私有服务提供；分享审核由 `src/accounts/share-admin.server.ts` 的独立私有服务提供，两者使用一次性令牌。账号站用 Better Auth 通行密钥登录，尚无全站管理员角色和公开个人资料接口。不能仅新增页面链接就声称管理已整合。

## 方案与选择

1. 汇总私有入口：改动少，但访问条件和登录仍分裂，无法直接在网站统一管理。
2. 在账号站增加统一管理员授权与后台，复用现有业务服务：本设计推荐。实现完整站内流程，保留原有私有接口及其验证。
3. 引入独立后台系统：需要重复身份、表单和业务逻辑，不适合本次需求。

用户已选择全站后台；第二种的身份和实现方案为实施者提议，待随本设计确认。

## 页面与首版功能

- `/dash`：概览，显示作品、版本、用户数量和待审分享数，提供模块入口。统计只读取真实数据库，不用占位数。
- `/dash/catalog`：作品与版本编辑、来源映射、现有验证报告和引擎状态。复用已有管理能力与并发修订检查，不额外触发转换、安装或文件删除。
- `/dash/classification`：已有作品、版本内容分级管理，保留证据、修订和冲突校验。
- `/dash/shares`：已有分享审核及审核记录；保留审核理由和并发检查。
- `/dash/users`：分页搜索账号 ID 和昵称，显示注册时间、主页是否公开及已有内容资格状态。用户详情复用现有资格暂停、恢复和资格撤销能力，要求理由与审计。首版不增加账号删除、封号、冒用登录或读取私人存档功能。
- `/u/:id`：ID 使用独立数字自增 UID，内部账号 UUID 保持不变；现有账号按注册时间、UUID 排序补号，新账号由数据库自动分配，不复用已分配编号，显示昵称、生成头像、简介、加入时间和该用户已审核且有效的公开分享。分享按访客的内容资格筛选；链接分享、待审分享和撤回分享不进入主页。
- 账号设置新增“个人资料”，支持编辑昵称（1–40个可见字符）、简介（最多200字）和主页公开开关；显示自己的主页链接。昵称同步账号显示名称，简介为纯文本。头像首版由昵称生成，无上传或第三方图片地址功能。

桌面后台使用分区侧栏与主内容区；手机改为可换行的分区导航。列表包含搜索、分页、加载、空态、失败和刷新反馈，表单保留未保存修改及冲突提示。

## 权限与隐私

沿用账号站通行密钥登录，在服务端通过 `WG_ADMIN_USER_IDS` 精确匹配管理员账号 ID；缺省为空，禁止首个注册者自动成为管理员。配置只在服务端读取，禁止通过请求、个人资料或客户端状态授予权限。账号接口只返回当前用户是否有后台入口，不泄露管理员名单。

后台页面和全部后台 API 都检查有效会话及管理员身份；未登录引导登录并安全返回，普通用户返回403。变更要求同源请求、请求体限制、业务字段校验及既有修订校验。后台响应禁止缓存；新增管理变更记录操作者、对象、动作、理由和时间，不记录令牌与私人正文。

原有私有管理入口保留；新站内后台通过服务端共用业务逻辑操作，不把私有一次性令牌传给浏览器，也不通过公开代理转发私有管理员身份。

现有及新账号主页默认关闭，由本人主动开启；关闭或不存在统一返回404且不泄露昵称等资料。本人在设置中可编辑预览。主页仅公开上述显式字段，书架、游玩记录、邮箱、设备、密钥、恢复码、存档及私密备注不公开。关闭后下一次请求立即生效，公开资料响应也禁止缓存。

## 实现边界

使用现有 React Router、Hono、PostgreSQL 和账号服务。个人资料通过新增版本迁移存储，迁移默认关闭公开开关；不能修改已执行迁移。具体模块拆分、分页大小和生成头像颜色由实施者决定，沿用仓库习惯，不新加依赖。

本轮仅开发和隔离环境验证。管理员账号 ID 的实际配置与生产发布单独处理，不擅自修改生产环境或数据；预览可创建隔离测试管理员验证流程。
