# 无 Worker 的浏览器 CAS 直连

用户已明确选择并授权实施：播放器通过数据库 API 取得 SHA256.bin URL，浏览器直接请求，Cloudflare 只缓存；验收通过后才清理旧资源。此次选择覆盖此前 Worker 路径兼容方案。不得引入新的边缘业务代码、Service Worker、正文转发服务或更换架构；若确需改变这些边界，先与用户讨论。

PG 是已发布资源映射的权威，复用作品版本与冻结 namespace 的绑定。API 只返回当前游戏的逻辑路径、抽象 key、哈希 URL、类型、大小、SHA，以及已登记共享引擎和媒体替代映射。浏览器父页面先取得这份清单，经现有专用消息通道交给 opaque iframe。游戏内仍用逻辑文件名；加载层在发起网络请求前把它转换为清单中的完整哈希 URL。ONS、JS/WASM locateFile、fetch/XHR、DOM 图片/脚本/音视频/字体、CSS url()/@import 均应覆盖。初始 HTML 的资源须在清单就绪前保持惰性，不能先发旧路径请求。CSS 如需改写，在浏览器处理已取得的正文，不通过应用服务器搬运资源。

数据链路固定：浏览器→主站 API（元数据）；浏览器→https://wg-b2.saop.cc/{64位小写SHA256}.bin→CF缓存→B2。API URL 以数据库返回值为准，并校验固定域、完整摘要、大小和 MIME，不能由任意输入提供 URL。CF 保留固定桶路径回源、缓存和 CORS/CORP 等静态配置，移除本项目在该域名的 Worker 路由。无 Worker 的资源请求不得再出现 /__player、/__ons、/__engines 或 releases 原键；不得用 302 或旧对象读取掩盖适配遗漏。

服务端保留目录、账号、存档、可信启动 HTML 与清单控制边界，不代理游戏、引擎或媒体正文。保存兼容身份、版本 ID、云存档协议、sandbox allow-scripts 且不含 allow-same-origin 均保留。当前最大游戏资源数49118（只读核实），清单须有限且压缩；新 API 不绕过发布检查。原始资源字节不改写、不重新上传，MIME 从现有源站元数据验证；若发现需改变存储布局/源站元数据的大范围操作，先报告实证再讨论。

先远程隔离验证，再上线同一构建并移除域名 Worker 路由。真实验收包括全部79版本的 API 对齐与哈希资源 HTTP/MIME/Range/CORS、ONS两例/Artemis/Tyrano/RenPy的真实画面或正文、保存退出和重进；浏览器网络必须证明正文直连根级 SHA.bin，主站不承载正文，CF无匹配Worker路由。保留失败记录，不以开始任务或模拟测试代替通过。

只有以上门槛通过且全量 CAS/旧版本与不可变清理计划再次核对后，才能按已授权清单逐版本删除旧公共资源。SQLite/PG映射、账号、存档和私有正文不在删除范围。延用已有精确版本执行器、进程互斥、部分结果核对和审计；未知数据/目标变化/服务端保护拒绝即停止。回退不得偷偷重新引入 Worker；若直连边界内无法恢复，先说明并讨论。

用户追加确认：去重后同一个SHA URL只有一个实际HTTP类型；API采用B2当前精确对象实际MIME，原始类型继续保存在PG源记录。公开对象可补实际类型与证明摘要，全部API投影一致，旧缓存不能继续返回原MIME；不修改B2对象、字节、版本ID或冻结原始映射。先在独立QA演练并比对，才写入生产PG。
