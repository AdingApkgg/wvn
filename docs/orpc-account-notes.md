# 账号领域 oRPC 迁移记录

- 账号目录、书架、阅读计时、资料、公开主页、内容资格、统计、收藏、通行密钥命名、导出与删除统一登记浏览器安全的输入和输出契约。
- HTTP 仍执行原 Hono handler，认证、业务校验、事务、Cookie、202 访客签发分支不变；契约输入失败沿用相应领域错误码。
- 页面调用使用 `account.api` 的详细输入；保留账号 owner、书架显示范围、页面存活与内容 epoch 校验。资格测试通过 `content.api` 接受返回的权限快照，切回公共浏览仍先收起页面再同步服务器。
- 输出包含 `noteHidden`、可选 SSR 会话摘要、分享脱敏字段与完整导出历史。导出历史字段允许既有数据库标量形式，但结构和嵌套存档仍显式校验。
- `tests/orpc-account.test.ts` 覆盖脱敏字段保留、非法权限状态、嵌套题目结果及导出存档结构。验证由主代理在远程构建机执行，本机未安装依赖或运行整库构建。
