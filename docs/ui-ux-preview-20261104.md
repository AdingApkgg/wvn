## 用户可以感知的变化

- 全站使用“发现、书架、存档、设置”四个任务入口；手机保留文字底栏。分享页只渲染一套页头，页内导航只保留当前任务的子区。
- 目录使用固定封面网格，已应用筛选可逐项清除并重置实际分页。关闭 JavaScript 后仍能展开筛选与提交 GET 搜索。
- 作品页修复手机标题、编号和互动区域重叠；默认显示中文简介，原文和版本细节按需展开。登录后回到原作品，加入书架仍需主动确认。
- 书架优先显示阅读列表，编辑按需展开。搜索、折叠和同账号资格复查保留草稿；离开先确认。收藏与阅读记录仍分别保存，只有本机确有副本时才称“继续阅读”。
- 浏览设置首屏先说明当前状态与下一步，完整规则随时可展开；资格、冷却、确认和服务端限制保持原规则。
- 阅读器区分游戏内存档、本机副本和云端备份；“结束阅读”准确说明结果。显示当前版本、引擎档案与已确认的云备份时间，加载失败提供恢复入口，全屏内可访问工具。
- 云备份按作品列出现有档案，上传文件按需展开；恢复确认复述来源时间和目标。公共浏览清除旧文件选择，下载使用中性文件名。
- 私有管理页从作品列表选择当前编辑对象；切换、搜索和折叠保留输入。分类证据按对象保留，草稿使用开始编辑时的修订，真正离开时提示未保存内容。

设计 token、组件状态、操作文案和响应式规则见 [设计系统规范](design-system.md)。设计依据与原始问题见 [审计](ui-ux-audit-20261104.md) 和 [设计系统规范](design-system.md)。

## 独立审查与修复

完成一次只读全分支代码审查，范围为 `47650f6..61cfbd9`。原结论为需要修复，未将它写成修复后复审通过。随后逐项处理：

- 公共投影增加 `noteHidden`，只提交用户实际改动的可见笔记；权限响应不一致时只改状态不会清空原笔记。
- 同账号复查期间草稿留在内存，敏感值从 DOM 移除；取消离开不创建阅读会话。
- 文件选择随档案/权限变化清空；历史文件经所属账号读取，再以当前范围允许的名称导出，不把真实名字留在下载链接。
- 后台草稿冻结原修订，其他对象保存或列表刷新不会为旧草稿换用新修订；分类草稿和离开保护补齐。
- 资源准备中或失败时显露高级区；错误不再静默吞掉；补上实际云备份时间和恢复源/目标。
- 阅读计时复用同页账号来源；统一确认在卸载后立即取消，关闭时恢复焦点。
- 清筛选重置 `offset`；更新原先假设筛选默认展开的两个旧测试。

新增的窗口复查、取消阅读和文件名回归先在旧预览复现 3 项失败，再验证修复。并行验证及空档不足的串行验证曾触发 QA 注册限流，另一次补验与构建产物切换交叠，已保留原日志并停止受影响作业；最终补验在稳定构建上运行，认证批次之间保留超过 60 秒的空档，不降低限流或生产授权。旧测试还修正了已保留的编辑展开状态、重复合成入口以及审核理由的可访问名称定位。

## 能力边界

- 预览使用 80 份既有公开 CAS 元数据快照，仅对齐现行固定 CAS 域名，保留对象摘要和字节数；不是全部 94 个版本的实时生产清单。
- 五类引擎验收只检查代表版本的真实启动、浏览器直接 CAS 请求和保留本机副本后结束，不代表所有作品完整剧情或所有存档兼容性已验收。
- 独立预览未配置生产的专用整包缓存来源；真实引擎走当前浏览器直连 CAS，整包缓存协议由已有相关测试覆盖，本轮没有新增缓存基础设施。
- 没有修改生产业务数据、资源对象、公开域名或缓存服务配置，也没有执行推送、PR、合并、发布或部署。
