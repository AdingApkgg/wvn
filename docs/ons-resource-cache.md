# ONS 资源预加载与浏览器缓存

ONS 的沙箱使用独立、不透明来源，旧的 `node.loaded` 仅属于当次内存文件系统。每次创建新播放器时都要重建内存文件系统；持久缓存让这一步复用本机资源字节，不能省去引擎初始化。

可信父页取得并校验当前作品的资源清单后，通过现有绑定 iframe、nonce、版本和 MessagePort 的通道提供只读资源代理。沙箱仅能请求本作清单中的文件键及固定校验值的共享 WASM，不能指定任意 URL、私有 API、其他作品或账号资源。所有网络请求省略凭据并拒绝重定向。保留 `sandbox="allow-scripts"`，不安装 Service Worker、不开放同源权限、不执行缓存中的游戏脚本。

浏览器独立数据库 `wvn-public-resource-cache-v1` 仅保存可重新下载的公共资源，与账号、存档及历史数据库分开。作品版本与资源清单摘要构成缓存范围，WASM 按内容校验值跨作品复用。命中时检查大小与 SHA-256；损坏、过期或版本改变时重新读取，部分响应和校验失败不会写入缓存。资源缓存有效期 7 天；同版本原地替换内容时可使用“清理本作资源缓存”立即重取。页面、清单与少量引擎 JavaScript 仍需联网，首版不宣称整站离线可用。

默认最多 256 MiB，同时最多使用浏览器报告剩余配额的四分之一。单文件最多 32 MiB，超出或无法确认大小时交回原有直接读取路径。缓存写入以同一 IndexedDB 事务完成元数据、文件和 LRU 淘汰，支持多标签页；不会触碰存档数据。空间或 IndexedDB 不可用时继续正常读取网络，并停止没有持久化收益的预加载。

启动所需资源先准备，游戏开始后空闲预载少量图片或音频，并围绕最近实际读取的资源补充邻近候选。后台串行，单文件至多 1 MiB，每次阅读最多下载 6 个、8 MiB，候选检查最多 24 次；不扫描资源盘或预载整部作品。有前台需求时取消无关后台下载，同文件合并请求，退出阅读时终止本次预加载。

加载面板区分“读取本机资源”和网络下载，保留原有大小、速度与百分比反馈。阅读操作下方显示本次缓存复用、容量与预加载状态；退出后可单独清理本作公共资源缓存，保留存档和历史。清理不删除其他作品或共享 WASM。
