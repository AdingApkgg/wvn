## 本批判断

此批区分同引擎同平台的真正内容分支，与仅因主机版、试读或翻译补丁自身字段引起的混合值。预测绘缘蜜恋、飞鸟两作可通过平台拆分消除混合；核查既有全发行索引后，二者false确实只来自Switch，Windows/Android Artemis及中文Windows译补均true，因此按用户接受社区标记的范围建议present。没有要求官方包哈希。

其余作品包括同Artemis的成人/Steam删减版，或ONS/WebGAL转换未说明来源，仍unknown。特别是虚之少女与SELECT OBLIGE不能仅过滤complete就排除可能部署的部分删减版。

新增KUN topic385可读，确认秽翼存在ONS及另一Tyranor移植；没有保留/删除成人内容说明，不能升级。新资源246、34276未能打开正文，不把搜索摘要当实际验证。CAS401、年龄/登录墙和前轮失败入口均未重试；未下载游戏或补丁。
