## 交付内容

- 新增 M3 色彩角色、五级色调容器、15 档字阶、形状、状态与交互目标 token，映射到 shadcn/ui；暗色暖铜主题继续使用系统字体。

- 使用 Motion 14.14.0 实现统一 Expressive 弹簧、导航共享指示、按钮按压、弹窗与页面进场；空间与 effects 参数分开，阻尼比按质量 1 转换。CSS 负责状态层、详情展开和兼容反馈。

- SSR 与关闭 JavaScript 时内容可见；减少动效取消空间和循环动画。空间 hover 仅在 `no-preference` 下启用，避免构建优化把 `translate` 重置合并成 `transform` 后失效。
- 独立审阅发现并修复 Radix Slot 覆盖按钮标记、Alert 缺少 variant、详情伪元素减少动效、长选项溢出、原生表单无效态和旧预览 Cookie 兼容问题。
- 新增运行中控制协议夹具，验证输入、全屏、弹窗和 iframe 稳定性。由此复现从游戏 iframe 首次点击存档按钮时，资格复查在按下和点击之间收起控件；存档面板现沿用原工具栏的鼠标焦点交接规则。真实窗口聚焦的资格复查保持原样。
