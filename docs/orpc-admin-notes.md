# 后台 oRPC 迁移说明

后台、私有目录管理和分享审核共用浏览器可读契约；动态前缀通过 `managementContract` / `moderationContract` 与对应客户端工厂生成。页面改用具名过程，作品与版本表单保留修订基线、草稿和指纹校验。

服务端仅替换 JSON 路由注册，原管理员校验、Origin、binding、近期认证、审计和数据库锁继续在原位置执行。私有一次性令牌登录、Cookie、201、409 和领域错误仍由原处理器返回。目录内部资源路径只出现在管理版本响应，公开目录的投影由独立契约负责。

新增 schema 用例覆盖工作文案指纹、分类层级与 payload 匹配、目录嵌套版本、审核队列 nullable 字段和动态路由路径。重负载验证由主代理统一在远程执行，本文件不代表远程构建或业务验收已通过。
