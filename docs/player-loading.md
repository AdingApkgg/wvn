# 播放器加载反馈

点击开始或继续阅读后，游戏区域立即显示独立加载面板，依次展示实际发生的连接、下载资源、恢复本机存档和准备游戏。下载进度来自浏览器 XHR 或 Emscripten 的状态回调；有真实总量时显示当前资源百分比，无法确定总量时使用不定进度条及已等待时间，不估算整部游戏的完成比例。

反馈沿用绑定具体 iframe、nonce 和游戏版本的专用 MessagePort。存档确认不覆盖加载状态；进度到 100% 不算阅读启动，仍只接受现有 `started` 信号。启动后隐藏面板，继续观察游玩中的资源请求。原引擎回调、请求参数、Promise、响应对象与下载字节保持不变；观察器自身故障不会中断引擎。

加载阶段可取消，失败时可返回阅读准备页后重试。取消只关闭本次沙箱，不删除本机存档或历史。加载期间游戏菜单及保存退出不可用；原生存档尚未就绪时立即提示，避免等待存档请求超时。原有导航保存保护继续保留。

四类运行区共用反馈：ONS、Artemis、Ren’Py、Tyrano。新增静态模块位于已许可的 `/ons/` 脚本范围，不扩大沙箱、CSP、跨来源权限或账号访问范围。支持键盘、进度条语义和减少动态效果偏好。

验证：协议边界、真实数量和更新频率、原生回调保留、下载响应不变、模块 CORS 白名单，以及远程真实引擎的加载、取消、失败、原生保存回归。预览验收不使用生产账号或私人云档。

游玩时，场景图片、音视频缓冲以及 fetch / XHR 资源加载会在画面顶部显示轻量加载条，完成自动收起。短于 180ms 的请求不会闪现提示；并发请求全部完成后才收起。只有总量完整可信时显示百分比，否则展示加载动画。请求失败显示 8 秒非阻断提示，不重新打开启动遮罩，也不禁止游戏菜单、保存或点击。

fetch 保留原 Promise 与 Response，仅观察原消费方法、reader 和浏览器 Resource Timing 完成记录，不 clone/tee 响应或额外下载资源。图片 src/setAttribute 适配叠加在匿名跨源适配器之上；持续监听不会带入账号凭据。媒体只跟踪到可用数据或恢复播放，不把整段音视频时长当作下载字节总量。缓存中立即可用的资源通常不会出现加载条。无法被浏览器观察的引擎内部计算不显示伪进度。

大小与速度：启动面板和游玩加载条显示已接收字节、可信的总大小及近期接收速度，统一使用 B / KiB / MiB / GiB。速度从实际字节增量与采样时间计算；1.5 秒无新回执时显示“等待数据”，首个有效采样前显示“测速中”。未知长度仍显示可测资源的已接收量，百分比保持不定进度。引擎自身的步骤计数继续用于原进度条，不被当作字节大小。

ONS 的资源文件和 WASM 使用显式流式消费器，在不克隆响应或额外请求的前提下逐块观察接收量；最终文件字节保持一致。其他引擎保留原消费方法，观察原生 XHR / reader 事件；DOM 图片等无法取得字节数量时显示“大小待获取”。压缩响应不使用压缩长度与解码后大小混算百分比，失败不会把尚未接收的字节补到总量。
