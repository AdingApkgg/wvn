# 切页加载优化

目录和作品页仅等待主体及权限判断。作品统计、玩家存档并行请求，以 Promise 返回，并在各自的 Suspense/Await 边界内补齐；接口失败不阻止作品入口使用。玩家存档筛选使用客户端导航。

目录卡片、主要导航、继续阅读和作品入口按悬停、聚焦、触摸意图预加载路由模块和样式。权限数据保持 `private, no-store`，仅在实际导航时请求，不进入浏览器或共享数据预取缓存。Cloudflare 不回源处理未命中的原生 prefetch，因此不为这些动态数据生成原生预取提示。

模块匹配沿用 React Router 已发现的路由树，资源路径来自框架构建清单；沿用现有路由发现协议，不提前加载所有页面代码或数据。

普通点击也立即预加载匹配模块的全部依赖。快速点击可能早于悬停的100ms门槛；如果只让路由器导入入口模块，浏览器会在入口下载后才发现尚未加载的静态依赖，多等一轮网络。链接原有点击处理先执行，取消、修饰键点击及外部入口沿用既有行为。

页面动效在绘制前直接设置位移起点，再由 Motion 弹簧驱动，避免内容先原位显示、下一帧再向下跳。路由内容不因动画重新挂载；阅读器和减少动效模式移除变换。

公共浏览切换的旧权限快照收起逻辑位于异步边界外，延迟到达的旧分享不会恢复显示。

异步数据使用新增的 `deferredCounts` / `deferredShares` 字段。旧 `counts` / `shares` 字段保留为 `null`，避免已打开的旧版组件把 Promise 当普通对象读取而报错。旧标签页刷新后使用新版统计和分享区域。

## 切页分段测量

2026-11-15的匿名线上样本采用点击事件、`MutationObserver`和下一次`requestAnimationFrame`记录主体DOM出现及下一帧，另采集浏览器网络瀑布。原Playwright元素等待器返回时间包含轮询/调度开销，不能直接当实际主体出现时间。

- 热缓存或意图预加载后的6次样本，主体DOM约412–438ms出现；其中多次等待器在791–799ms才返回。
- 数据请求首字节约395–449ms；源站回环约51–77ms，后者包含本地TLS。差值覆盖本次代理、公网、CDN和源站连接链路，不能单独归因某一环节。
- 冷启动对照各4次：未处理组主体DOM约760–1088ms，中位967ms；在测试浏览器点击时注入整组静态依赖预加载后，约417–841ms，中位520ms。依赖发起由点击后368–680ms提前至约1ms。

两组按先后顺序执行，样本较小且走远程专用代理，不代表用户p95或所有网络的提速比例。并行请求的机制另以回归验证：阻塞入口模块响应时，依赖仍须先发出，不以不稳定的绝对耗时作为断言。

## 公共目录主体复用

无筛选公共目录可在内存保留最多100部已审核SFW作品的公共投影，30秒过期。不保存账号、权限结论、统计、分享或持久化数据；受限/未审核主体和带查询参数的作品页沿用最新请求。

命中时`clientLoader`仍立即请求服务端，先展示公共主体，随后由`Await`替换为最新结果；请求失败、删除或权限拒绝时收起旧主体。确认前书架写操作禁用。仅普通命中导航跳过根快照的重复等待；同URL复查和表单提交沿用根loader校验。目录预加载轻量clientLoader代码，以免未命中时先下载该模块再请求数据。

权限/账号变化、跨标签事件、离开或隐藏标签页时清空缓存。同一目录快照重渲染不能延长时效或复活失效数据，快照身份仅以弱引用记录；只有新取得的目录结果能重新播种。直接打开作品及无JavaScript访问保留SSR。

最终受控QA对照（2026-11-15）：同一实现通过失效公共缓存作为未命中组，数据请求人为延迟400ms。低代码下载延迟组各8次，主体DOM中位459ms→28ms，下一帧中位478ms→94ms，命中组后台确认中位556ms。代码模块也人为延迟400ms时，各4次主体DOM中位552ms→457ms。两组顺序执行，主机存在I/O与调度抖动，不能视为线上p95或保证收益；初次代码下载仍是下限。权限初始化完成信号与当前账号绑定及根快照对应，避免初始化复查清空刚播种的快照。

最终4项单测及11项主体/导航权限回归通过。此前完整41项批次未通过，包含初始化问题与账号/阅读器超时；最终版仅完成相关用例复核，完整阅读器回归仍待稳定环境核验。主体复用保持草稿，未部署生产。
