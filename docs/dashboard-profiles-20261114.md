# 全站后台与数字 UID 个人主页

日期：2026-11-14。代码、远程类型检查、构建与隔离验收完成；用户随后授权生产发布，现已切换并配置管理员，稳定性观察进行中。生产详情见 [生产记录](dashboard-profiles-production-20261114.md)。

## 使用方式

- `/dash`：全站概览、作品与版本、内容分级、分享审核、用户查询与资格管理、操作记录。
- `/u/:uid`：数字 UID 公开主页。UID 以字符串返回，内部 UUID 保持原样；老账号按注册时间及 UUID 确定补号，新账号由 PostgreSQL identity 和注册触发器分配。关闭或不存在的主页均为404。
- 登录账号后进入“设置 → 个人资料”，修改昵称、简介及公开开关，开启后可打开“查看我的主页”。头像由昵称生成，无需上传。
- 公开主页只展示显式资料和已审核且有效的公开分享，不展示书架、游玩记录、私人存档、邮箱、设备或恢复信息。链接、待审和撤回分享不会进入列表；分享列表经过实际最外层内容资格过滤。

## 管理员配置

`WG_ADMIN_USER_IDS` 是服务端内部账号 UUID 的逗号分隔名单，默认空；不是数字 UID。本人账号导出包含 `user.id`（UUID）和 `profile.uid`（公开编号）。将目标 UUID 配到账号服务环境后重启账号服务；不将配置写进客户端，不通过注册顺序授予权限。

预览阶段只配置测试管理员。用户随后确认正式账号 Asuna（7437c74e-ed0e-417a-b7c2-29bef0a924f9）并授权发布；生产已完成资料迁移和该账号的管理员白名单配置。不能将预览会话或测试账号用于生产。

所有后台 API 和页面都验证账号会话及名单。变更沿用 Origin、请求体限制和会话绑定；目录、分类和审核沿用原有修订校验。旧私有管理监听器继续使用原令牌流程。新后台共用业务处理器，不公开私有管理员令牌。

`009-public-profiles-dashboard` 是新增迁移，不修改现有已发布迁移。资料随账号删除通过外键清理；备份沿用全 schema 的 PostgreSQL 导出，本人资料加入账号导出。UID sequence 不因账号删除而重置，不保证无空号。
