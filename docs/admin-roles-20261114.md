# 后台分配管理员权限

用户要求允许管理员给其他用户分配管理员权限。本轮采用数据库持久化角色，账号接口、后台页面和API都查询同一权限来源；配置中的Asuna保留受保护管理员。其他管理员可授予或撤销其他用户的权限，不能修改自身或受保护管理员。

权限变更要求现有会话绑定、同源请求、10分钟内的通行密钥验证、理由及当前权限修订。事务内重新验证操作者、串行化权限变更，角色和审计同时提交。新权限在下一次请求即时生效，不依赖重启；撤销不影响普通账号、书架或存档。

实施与验收顺序：先编写并观察权限HTTP测试失败；新增010迁移、共享管理员仓储与API；用户列表增加角色标记和确认表单；验证授权、转授权、撤销、现有会话即时失权、受保护账号、自改权限、旧验证、并发冲突和原子审计，完成远程类型/构建及浏览器验收。
