## 本轮排障与恢复

生产发布前发现 Tyrano 的 `tyrano/plugins/kag/kag.tag_system.js` 在 B2 按文件 ID 和按名称下载均持续返回 500/503。退避 7 次仍失败后，使用 Alice 保留、完整摘要相同的 14,303 字节文件新增同名 B2 版本。SHA-256 为 `bfa932c7d173adbf64709a25af211f56ff9f022bbbc3d0a43c5536130cd3c09c`，SHA-1 为 `da40ca5ae09fcfcdb5ccee9fd2681ce7d73b2bd1`。旧版本和原元数据保留，桶生命周期规则、Cloudflare 和冻结数据库映射未改；新版本完整下载与 Range 下载通过。

真实浏览器验收另发现 CDP 流订阅可能晚于小清单下载完成，已补同一请求的缓冲正文读取。公网客户端还会在退出时取消已经完整消费的 fetch：CLANNAD 的 19,314,253 字节清单完整摘要与独立证明相同，CDP 仍报告 `ERR_ABORTED`。最终浏览器验收旁听父页实际送入运行沙箱的初始化消息，逐项比较引擎真正收到的清单；不拦截、重发或改写请求与消息，重复初始化拒绝。退出断言只检查游戏 iframe，另一个隐藏非游戏 iframe 不计为游戏残留。两项行为均有真实浏览器回归。内网预览地址显式绕过外部代理，B2 和正式公网请求继续走已配置代理。

前两次应用切换未通过部署探针并回退：生成配置的换行转义错误已修正，随后发现探针必须使用服务真实绑定地址与生产 `Host`。最终启动前会验证配置行、systemd 解析出的工作目录和原服务健康标识。回退只隐藏本轮新增版本并恢复原应用；搜索触发器所需的 `catalog` search path 已显式设置。各次回退没有恢复旧账号库或删除数据。

后续公网验收发现《繁花落舞恋如樱》新增版与《樱之刻》新增版的 FX 编译失败。两版先单独隐藏，原默认版保留。实际失败的两组各 19 个程序摘要全部已在既有兼容清单内，原因是遗漏了这两个版本的启用范围。补丁仅增加两个版本 ID，原 28 个程序摘要、转换算法、WASM、B2 正文和存档身份均未改。完整构建、测试、GPU 和原生预览通过后发布，再恢复这两个入口；其最终公网清单摘要与原独立证明一致。

最终静态模块并行核验遇到连接超时后，保留 10 项已通过记录，仅补验其余 3 项，13 项摘要全部一致。没有修改服务来绕过检查。

94 版清单一致性证明的是资源身份与投递链路；浏览器抽测和新增版本验收的覆盖范围以本轮报告为准，不等于全部游戏完整通关。源站核心包缺失的《圣女不死心》仍未作为可玩版本发布。
